# The Socket: Gravity-Gone feature workspace

Self-contained static feature route for the existing ReeferDude website.

Includes smoke animation, floating islands, portal transitions, a Three.js conceptual room preview with orbit/zoom controls, room-planning estimates, hypothetical Strain Weaver, local educational Kali Kush demo, localStorage cultivation journal with JSON export, searchable Cannabis Cosmos glossary and knowledge topics, responsive layout and reduced-motion support.

Important: the chat is a local demo, not a live AI model. The grow-room outputs are educational estimates, not engineering or compliance advice. Strain Weaver does not predict inherited traits, potency, safety or viable cultivars. Journal data stays in the current browser. Three.js loads from jsDelivr; self-host it for offline/CSP use. No cannabis sales, medical advice or legal advice are implemented.

Open /socket/ on the deployed website. For a Vite/React project, copy this folder to public/socket and open /socket/.
