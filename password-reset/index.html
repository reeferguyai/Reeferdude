Password Reset: Get Back In

Locked out happens to everyone. Enter the email on your account and a reset link goes out immediately; the link lives for one hour, works once, and signs out every other session when the new password is set — the way it should work everywhere.

No email arriving?

Check spam first, then give it ten minutes — mail gremlins are real. Still nothing? The account may use a different email than you think; contact support from the contact-by-topic page and a human will sort it without ever asking for your password. Nobody here will ever ask for it.

Demo note

Accounts on this demonstration storefront run in preview mode — sign-in itself is presented in the log in page as a design — so password reset shows the real flow without live accounts behind it yet.

Make it a good one

Length beats cleverness: a passphrase of four plain words outlasts any symbol salad. A password manager turns the whole problem off; the security page links the reputable free ones.
